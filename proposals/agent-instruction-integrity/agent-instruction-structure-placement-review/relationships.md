# Relationships: Agent-Instruction Structure and Placement Review

## Potentially selected by: adaptive review-panel coordination

Type: prospective consumer relationship.

Adaptive coordination may select this specialist when the review subject
contains materially normative agent-facing text. Selection does not transfer
finding ownership to the coordinator, and availability does not make the
specialist applicable.

## Currently selected by: bootstrap proposal-review procedure

Type: interim operational consumer relationship.

Before adaptive coordination is accepted and implemented, the bootstrap
procedure may select this specialist for a proposal whose present subject
contains actual normative agent text. The procedure owns the interim selection
and immutable review subject, not the specialist's findings or semantic
contract. A proposal that merely anticipates future instruction implementation
still omits the specialist truthfully.

## Potentially publishes through: revision-bound review artifacts

Type: prospective representation relationship.

A mature workflow may represent instruction findings, evidence, limitations,
remediation, and applicability through the shared review-artifact profile. The
initial skill and dogfood can use exact Git-bound Markdown records without
accepting that candidate's permanent placement.

## Advises: proposal formation

Type: conditional information relationship.

When a proposal contains actual normative agent text, findings may justify
candidate revision. A proposal that only anticipates a future skill does not
receive speculative instruction review, and the reviewer never owns proposal
meaning or revision.

## Complements: architectural, doctrine-authority, and seam review

Type: distinct specialist relationship.

Architectural review owns diagnosis of the system model; doctrine-authority
review owns broader binding and authority conflicts; seam review owns
correspondence between independently valid contracts. Instruction review owns
the narrower structure, reach, and placement of normative agent text. A panel
may select several without collapsing their findings.

The compact two-question diagnostic is shared reasoning vocabulary across these
roles. Ownership follows the diagnosed subject and consequence, not possession
of the questions: this specialist does not absorb doctrine, architecture, or
seam judgments merely because they use the same reduction.

## Reviews outputs of: skill and workflow authoring

Type: primary implementation-review relationship.

Authors and builders mutate instruction surfaces. This specialist reviews the
immutable implementation subject and advises remediation; it does not become
the author or implementation acceptance owner.
