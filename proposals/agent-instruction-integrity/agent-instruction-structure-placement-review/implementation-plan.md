# Implementation Plan: Agent-Instruction Structure and Placement Review

This is a possible delivery shape for the formed candidate, not implementation
authority or a mandatory route. Steps may be combined, reordered, or revised
when another path preserves the same outcomes and independence boundaries.

## Bootstrap subjects and distinctions

Bind small immutable subjects that include one causally necessary exact route,
one unnecessary concentrated route, one mixed invariant/mechanism instruction,
and one hidden objective or authority boundary. Include materially similar text
at different instruction layers so placement changes the correct judgment.

## Specialist skill

Create a bounded skill whose core remains the two-question diagnostic and whose
placement context is loaded only when relevant. Keep output semantic and
evidence-bearing rather than imposing a sentence-by-sentence form or a closed
list of acceptable instruction types.

## Independent bootstrap review

Have a fresh, independently defined review capability apply the accepted
candidate contract directly to the implemented skill and supporting
instructions. Its review contract and rubric must not be the newly built skill
under test, and it must not inherit builder reasoning or treat the skill's own
output as proof. Preserve findings and ordinary same-session remediation
through the established review path.

## Real dogfood

Review the retained-Claude workflow instruction surface in
`skills/claude-recon-implementation/SKILL.md`, `skills/work-engine-mcp/SKILL.md`,
and `reviews/proposals/bootstrap-review-procedure.md`. Compare its findings with
architecture, doctrine-authority, and seam perspectives only where those
perspectives have credible decision value.

## Conditional panel consumption

Exercise one implementation review with material agent-facing text, one
proposal containing an actual instruction contract, and one proposal that only
anticipates a future skill. Confirm truthful selection and omission without
requiring the unimplemented adaptive coordinator as a prerequisite.

## Placement and artifact decision

Use observed context cost, distinct findings, false positives, causal-route
preservation, remediation behavior, and consumer needs to decide permanent
skill naming, supporting references, proposal-versus-implementation reuse, and
review-artifact/state integration.
