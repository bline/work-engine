# Relationships: Production Claim Evidence Interface

## Split from: claim-centered evidence lineage

Type: causal decomposition.

This proposal selects the stable production record and interface substrate from
the complete semantic parent. It preserves the parent's full model and does not
supersede, accept, or rewrite the parent's deferred decision.

## Enables: claim maintenance and reliance propagation

Type: causal production dependency.

The dependent phase requires production claim identities, exact revisions,
authority-bound publication, reliance records, domain profiles, and truthful
query projections. Phase one makes those foundations available but cannot
claim the dependent lifecycle is complete.

## Related to: revision-bound review artifacts

Type: initial domain profile and consumer.

Review findings exercise the common statement identity, evidence, provenance,
authority, sensitivity, and lineage core. Review artifacts retain their own
episode, severity, conflict, synthesis, and outcome semantics.

## Related to: durable proposal packets

Type: exact-revision consumer.

Proposal packets or supporting artifacts may record reliance on a claim
revision for one decision scope. Claim publication or later revision never
mutates, accepts, or reopens the proposal automatically.

## Projection relationship: Work Engine MCP

Type: external read-only transport; non-owning.

The MCP adapter may expose the same bounded query semantics to an external
reviewer. Transport differences do not change state meaning, completeness,
freshness, provenance, or authority.
