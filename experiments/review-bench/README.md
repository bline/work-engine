# Review Bench pilot data

Corpora, results, scoring and reports from the review-bench pilots
(`pilot/`, `pilot-v1.1/`, `pilot-v1.2-role-state/`, `pilot-v1.2-slice14/`,
`pilot-v1.2-visual-observation/`, and `pilot-candidates.json`). The tooling that
produced them is the [review-bench skill](../../skills/review-bench/SKILL.md).

These files moved here from `skills/review-bench/` on 2026-10-27 so that skill
releases no longer copy research data. All 51 are byte-identical to their old
paths. Each one's SHA-256 is cited in records, including
`skills/linguistic-register-pilot/pilot/micro-render-v2c-leakage-audit/subject-inventory.json`,
and those citations still match. Records that name the old
`skills/review-bench/pilot*` paths are left as written; read them with
`skills/review-bench/` replaced by `experiments/review-bench/`.
