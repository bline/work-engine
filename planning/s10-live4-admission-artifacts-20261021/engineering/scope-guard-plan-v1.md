# Concrete stopped-custody guard selected for postapproval qualification

**Static plan, not executed.** No historical live4 runner has an independently verified descendant stop. Current `run_semantic.py` marks `detached_descendants_verified=false` and downgrades a mechanically positive run to `uncertain_teardown`. Its own process-group check cannot be upgraded by assertion. The available host has cgroup v2, `/usr/bin/systemd-run`, and a responsive user systemd manager (`systemctl --user show` returned Version 259.5 and a user ControlGroup); this is read-only availability evidence, not qualification of a transient scope.

Select a **unique user-systemd transient scope for the whole one-shot runner**, controlled by an external process outside that scope. The static draft `packet-src/scope_controller.py` launches `systemd-run --user --scope --unit=s10-live4-<unique>.scope --property=KillMode=control-group --property=SendSIGKILL=yes --property=Delegate=no --property=RuntimeMaxSec=1230s --wait /usr/bin/python3 <exact-frozen-runner> --live-armed`. The runner blocks on a scope gate before source checks or state creation. The controller releases it only after the user manager reports an active nondelegated scope, the exact runner PID/starttime is a member of that cgroup, and the gate records those identities. The controller records the cgroup path, members and starttimes; the existing predecessor script separately captures the actual host PID/starttime for the restart declaration. Do not infer host PID from the `systemd-run` process PID. Credentials pass through the existing private environment, never arguments or logs.

The controller owns deadline and cleanup. On normal runner exit or any error, request `systemctl --user stop <unit>` and, after a bounded grace, `systemctl --user kill --kill-whom=all --signal=SIGKILL <unit>` if any member remains. Query `ActiveState`, `Result`, `ControlGroup` and the captured cgroup's `cgroup.procs` until the unit is inactive and the cgroup has no members (or has disappeared **after** the user manager reports it inactive). A present but unreadable cgroup fails closed. Record exact timestamps, command exit codes, final unit state and observed PID/starttime membership. `controller_explicit_escalation=false` says only that the controller did not request SIGKILL; systemd may still have escalated or signalled a process internally. The receipt records actual signal/termination mechanism as unknown unless independently observed. Individual detached descendants' exit codes may remain unavailable and are never called natural exits. **Only after this external check** does the draft controller copy task and lifecycle SQLite plus WAL/SHM to `stopped-copy-final`, verify before/after hashes, then permit the raw-first extractor. The runner's `stopped-copy-provisional` is never accepted custody. A separate external receipt joins its original `uncertain_teardown` result without rewriting it. The reviewer may treat the combined evidence as clean only if the external scope and stopped-copy order are exact.

Postapproval offline gate before any paid send:

1. With no provider credential, launch a disposable synthetic process in a unique user scope that spawns a `setsid` child. Verify the child remains in the same cgroup even after changing process group/session, then stop the unit and prove both parent and child are gone from `cgroup.procs` before copying any sentinel file. Record all PIDs and `/proc` starttimes to avoid PID-reuse confusion.
2. Apply the same controller to the selected exact host under the controlled fake route. Verify predecessor identity for restart declaration, the runner's first/second recorder ack pauses, 20-minute and >13-turn/effect stop branches, and normal/forced/host-crash cases. The controlled host and native descendants must remain in the unique scope; fail if not.
3. Exercise stopped DB/WAL extraction **after** scope inactivity for clean and forced cases. Inspect task schema2, lifecycle schema7 and raw model material. Prove that an uncertain or still-live scope never publishes a clean stopped-copy receipt.
4. Freeze the controller source, commands, checks, result schema and exact run logs in the candidate manifest; obtain reviewer acceptance. If systemd scope creation, PID attribution, cgroup membership or stop/quiescence proof fails, no paid live send. Do not substitute a process-group-only report.
