## Deliverable and acceptance

The proposed change is confined to the Web/sync consumer and its integration
fixtures. The public mailbox can remain; a local sync client can call AH's
protected service-to-service HTTP profile. Browser access to the laptop and new
remote OAuth/client policy are not prerequisites. Existing Python/browser
components may be evolved; any new independently runnable first-party adapter
uses Rust under the existing language direction. No second backend, verifier,
admission journal or runtime launcher belongs to this change.

The accepted result must establish:

1. The actual AH process and selected domain owners serve a pinned task/request
   projection through the Web/sync adapter. Current and replacement Web views
   render the same supported terms, source revisions and unavailable fields.
   Repeat the actual consumer flow with MCP disabled. An in-memory substitute
   for AH does not satisfy this integration claim.
2. A fixture answer's unchanged exact string reaches the existing verifier and
   selected owner path through the composed Web/mailbox/sync/AH topology. The
   reported receipt distinguishes storage, delivery, verified decision and any
   later admission. Preserve RP/origin, user verification, pins and currentness;
   fixture authentication remains visibly fixture evidence.
3. Changed/closed requests, wrong owner/key/origin, expired terms, stale source
   revisions, unsupported profiles and missing owner capabilities are denied or
   held at their owning boundary. Account change/cancellation while signing
   cannot submit stale material. No transport failure becomes an empty healthy
   projection or a successful decision.
4. Duplicate answers and a lost acknowledgement retain the owner's replay and
   uncertain disposition without a second decision/effect. Exercise sync/AH
   restart and owner outage against disposable local state; recovery evidence
   covers the selected interface, not untested provider execution.
5. Both the existing mailbox-backed Web path and its selected alternative local
   adapter preserve those observations and exact answer semantics. Existing
   browser, JavaScript, Python and affected Rust checks pass, with source/config
   identities bound in custody records. Tests do not use production Redis,
   actual owner credentials, live inference or deployed Stytch.
6. A separate read-only Astra high review accepts the frozen source and joined
   process evidence after any bounded repairs. Deliver an exact commit/handoff
   and state what remains outside A4.2 and overall A5 release conformance.
