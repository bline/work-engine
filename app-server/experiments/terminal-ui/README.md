# Terminal UI moved

The maintained standalone app is now at
[`rust/crates/terminal-ui`](../../../rust/crates/terminal-ui/README.md).

```sh
cargo run --locked --manifest-path rust/crates/terminal-ui/Cargo.toml
```

This directory retains only this relocation notice. Historical evidence may refer
to the former location; the app still uses fixtures and offline replay until
runtime integration is implemented.
