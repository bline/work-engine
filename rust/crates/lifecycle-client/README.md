# Lifecycle read client v1 (U0 contract)

`ReadClient<T: ObservationTransport>` exposes only `snapshot(subject, budget)`, `wait(subject, target, budget)` and `reconnect(subject, previous_cursor, budget)`. The transport port has `snapshot(subject, optional_target, budget)` and passive `wait_hint(subject, target, cursor, budget)`; it cannot submit commands. A targeted snapshot exposes the named durable delivery or transition even if later records are current, while admission remains current. `wait` rereads after each hint, performs a full targeted snapshot read on an explicit cursor-gap signal, and returns observed, deadline-expired with last seen, or observation-unavailable. Global journal sequence jumps alone are not gaps. Reconnect refuses a different store or stream identity and a lower sequence. `UnixSocketTransport::new(path)` is the S4 implementation; it bounds each read and write by the supplied budget and one 131072-byte frame.

The [v1 schema manifest](../lifecycle-wire/schemas/v1/manifest.json) is the published U0/S3 artifact (SHA-256 `f4c73a45602284989fc352f5529f421a5e2c73cdaece2c4678035825032727be`). Its source hashes describe that historical publication; S4 source extension does not rewrite the manifest. Generate v1 schemas only into a temporary directory and compare the five schema bytes. The [v2 command manifest](../lifecycle-wire/schemas/v2/manifest.json) owns the separate four-field text command and command-result contract. The read snapshot/wait protocol remains v1.

S4's U1 controlled proof launches the actual service and a separate controlled peer, observes a historical transition through this client after the sender disconnects, kills/restarts the service, and calls `reconnect` against the persistent store identity. The service socket directory must be owned by the configured local user and mode `0700`; the socket is `0600`. Request bytes use one JSON object followed by `\n`: `{"op":"snapshot","subject_id":"...","delivery_id":null,"transition_id":null}` for a current read. The client uses targeted IDs only when waiting for a named delivery or transition. Snapshots omit raw input and final response text. This client has no mutation method or dependency on S1 store, S2 runtime, or provider crates.
