# Lifecycle read client v1 (U0 contract)

`ReadClient<T: ObservationTransport>` exposes only `snapshot(subject, budget)`, `wait(subject, target, budget)` and `reconnect(subject, previous_cursor, budget)`. The transport port has `snapshot(subject, optional_target, budget)` and passive `wait_hint(subject, target, cursor, budget)`; it cannot submit commands. A targeted snapshot must expose the named durable delivery or transition even if later records are current, while admission remains current. `wait` rereads after each hint, performs a full targeted snapshot read on an explicit cursor-gap signal, and returns observed, deadline-expired with last seen, or observation-unavailable. Global journal sequence jumps alone are not gaps. Reconnect refuses a different store or stream identity and a lower sequence. The transport must honor every supplied remaining I/O budget; the S4 socket implementation must prove that bound and provide the historical target lookup.

The [v1 schema manifest](../lifecycle-wire/schemas/v1/manifest.json) pins protocol and codec labels, Draft 2020-12 generation settings, source/schema/fixture SHA-256 digests, and unsupported-variant behavior. Run `cargo +1.92.0 run --manifest-path rust/Cargo.toml -p lifecycle-wire --example generate_schema_bundle --locked -- rust/crates/lifecycle-wire/schemas/v1` from the repository root to regenerate the bundle. Compare the manifest file's own SHA-256 when transferring U0. Fixtures show failed execution with unsettled effects, unavailable observation, historical transition completion while current admission is blocked, and unsupported observation variants. The compatibility fixture pins representative command and failed/unsettled snapshot canonical bytes and digests against an independent JavaScript implementation.

U0 contains contract examples, not observations from a running service. S4 owns coherent committed-state reads, socket authorization/redaction, store-backed resync, and the U1 live client proof. Command DTOs are data; grant resolution and submission remain a separate authenticated service boundary.
