# Session query client

This temporary client calls the existing session-events MCP owner through a pinned local Python adapter. It does not own transcripts, operation journals, authorization or reconciliation. The Rust CLI accepts a local JSON profile with absolute `helper`, `owner`, `owner_sha256`, `codex_home`, `claude_home`, and `state_dir` paths; `bridge` additionally supplies `binary`, `binary_sha256`, `config`, and `config_sha256` for granted reads. The bridge validates its own binary and private configuration. Arguments are JSON supplied on stdin (`-`) or a private file, never as command-line JSON. Output is `work-engine.session-query.v1` JSON or a human-readable rendering. Native session IDs remain session IDs.

Example: `work-engine-query profile.json list_sessions --json -` with `{}` on stdin. The four admitted queries are list_sessions, read_session, read_session_operation, and read_session_result. MCP remains a sibling consumer of the same owner. Remove or replace this adapter when the accepted A3 session-owned Rust query implementation takes over the compositor and preserves the granted operation and result semantics; this adapter does not authorize that replacement.
